# ยูนนาน YUNNAN IMPORT - ระบบบริหารจัดการแต้มสะสม & บัตรสมาชิกดิจิทัล (LINE OA / Web POS)

ระบบบริหารจัดการแต้มสะสมและสิทธิประโยชน์สมาชิก ออกแบบในธีม **ยูนนาน (Yunnan Import)** หรูหรา สไตล์หยกและทองโบราณ (Imperial Jade & Antique Gold) พัฒนาขึ้นมาใหม่ทั้งหมด พร้อมเริ่มต้นเป็น **ระบบหน้าเปล่า (Clean Slate)** พร้อมสำหรับเริ่มบันทึกข้อมูลสมาชิกร้านจริงได้ทันที

---

## 🌟 ฟังก์ชันเด่นของระบบ

### 1. หน้าจอแดชบอร์ดแอดมิน (Admin Store Management - `http://localhost:3000`)
- **ธีมร้านยูนนาน (YUNNAN IMPORT)**: โทนสีเขียวหยกจักพรรดิ (#064e3b) และทองโบราณ (#c59b4e) พร้อมโลโก้ร้าน
- **สถิติภาพรวม Real-time**: สมาชิกทั้งหมด, แต้มคงเหลือในระบบ, ยอดซื้อรวมสะสม, ของรางวัลที่แลกไปแล้ว (เริ่มต้นที่ 0)
- **ระบบ LINE OA LIFF Integration**: มีช่องแสดง URL และปุ่มกดคัดลอกลิงก์สำหรับนำไปใส่ใน Rich Menu ของ LINE OA ได้ทันที
- **จัดการสมาชิก (Member Management)**:
  - เพิ่มสมาชิกใหม่พร้อมกำหนดแต้มต้อนรับ (Welcome Points)
  - ค้นหาสมาชิกด้วยชื่อ, เบอร์โทรศัพท์, รหัสสมาชิก และกรองตามระดับสมาชิก (Tier)
  - ปรับเพิ่ม/ลดแต้ม (Manual Adjust Points) พร้อมระบุเหตุผล
  - ดูบัตรสมาชิกดิจิทัล พร้อม QR Code & Barcode จำลอง
- **จัดการของรางวัล (Reward Catalog)**:
  - เพิ่ม / แก้ไข / ลบ ของรางวัล (ชาผูเอ่อร์, สินค้ายูนนาน, คูปองส่วนลด, ของพรีเมียม)
  - ตั้งค่าแต้มที่ใช้แลก, จำนวนสต็อก, หมวดหมู่, ระดับสมาชิกขั้นต่ำที่แลกได้
- **ประวัติการแลกของรางวัล & ตรวจสอบคูปอง (Redemptions & Voucher Validation)**:
  - ช่องกรอกรหัสคูปองเพื่อตรวจสอบความถูกต้องและกดยืนยันการมอบของรางวัล
- **ประวัติบันทึกแต้ม (Transaction Audit Log)**:
  - บันทึกทุกรายการเคลื่อนไหวของแต้มอย่างละเอียด

### 2. หน้าจอแคชเชียร์หน้าร้าน (Cashier POS Station - `http://localhost:3000/cashier.html`)
- ค้นหาสมาชิกด่วนด้วย **เบอร์โทรศัพท์** หรือ **รหัสสมาชิก**
- เมื่อเลือกลูกค้า ระบบจะแสดงชื่อ, Tier, และแต้มคงเหลือแบบเรียลไทม์
- กรอกยอดซื้อสินค้า (บาท) มีปุ่มคีย์ลัด (+50, +100, +200, +500, +1,000)
- **ระบบคำนวณแต้มอัตโนมัติแบบ Live Preview** พร้อมคำนวณโบนัสตามระดับสมาชิก (Tier Multiplier เช่น Gold x1.2, Platinum x1.5, Diamond x2.0)
- บันทึกยอดซื้อและสะสมแต้มทันที พร้อมเสียงแจ้งเตือน (Chime Sound Effect) และเอฟเฟกต์พลุฉลอง (Confetti)
- ระบบแจ้งเตือนอัตโนมัติเมื่อลูกค้ามียอดซื้อสะสมถึงเกณฑ์เลื่อนระดับ (Tier Upgrade)
- แลกของรางวัลหน้าร้านทันที (In-Store Instant Redeem)
- ตรวจสอบรหัสคูปองของลูกค้า (Voucher Check)

### 3. พอร์ทัลบัตรสมาชิกดิจิทัลสำหรับลูกค้า (LINE LIFF View - `http://localhost:3000/member.html`)
- ดีไซน์สวยงามระดับ Luxury Virtual Card สไตล์ยูนนาน หยกเขียว & ทอง (Silver, Gold, Platinum, Diamond)
- แสดง QR Code & Barcode ดิจิทัลสำหรับให้พนักงานสแกนหน้าร้าน
- หากยังไม่มีสมาชิกในระบบ มีหน้าจอให้ลูกค้ากรอกชื่อและเบอร์เพื่อ **เปิดบัตรสมาชิกได้ทันที**
- ลูกค้าสามารถกดดูแคตตาล็อกของรางวัลและกดแลกของรางวัลได้ด้วยตนเอง
- เมื่อแลกแล้วจะได้รับ **รหัสคูปอง (Voucher Code)** เก็บไว้ในแท็บ "คูปองของฉัน" สำหรับนำไปยื่นหน้าร้าน
- ดูประวัติแต้มเข้าและแต้มออกของตนเองได้แบบละเอียด

## 🚀 วิธีเปิดใช้งานระบบ

### วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานทันที (แนะนำ)
1. ไปที่โฟลเดอร์ **`C:\loyalty-reward-system\`**
2. ดับเบิลคลิกที่ไฟล์ **`start.bat`**
3. หน้าต่าง Command Prompt จะเริ่มรันเซิร์ฟเวอร์
4. เปิดเว็บเบราว์เซอร์ไปที่ `http://localhost:3000`

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
cd C:\loyalty-reward-system
node server.js
```
